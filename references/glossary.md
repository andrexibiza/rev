# Rev Glossary (normative definitions; conflicts resolved in favor of this file + authority.md)

Coordinate: any string/state identifying candidate operation without granting it (branch, tag, CVE ID, env name, socket, PID). Proof Object: explicit current authority bundle (schema §5.1). Generation: monotonic incarnation discriminator per repo/object. Pin: (SHA, generation, policyHash) triple. Seam: boundary where unchanged code changes behavior. Distinguisher: observation separating success/failure worlds. Sensitivity: distinguisher proven able to go red. Radius: downstream consumer/seam/owner closure at pin. Lane: information-isolated agent role execution. Geometry: declared lane configuration (full 5x2x3 or declared compression). Settlement: typed terminal/indeterminate outcome + receipt. SHIPPED: slices delivered as linked PRs. MERGED: merge SHA verified green on main. NO_ACTION: verified unreachable/unexploitable advisory closure. Interlock: bidirectional issue/PR/advisory/receipt graph. Manifest: manifested debt ledger with frozen allowances (2K, flaky, flags, legacy docs). Germinated: docs locale passing parity gates + semantic witness at error tier. Refusal: typed protocol success naming broken path + next action. Wrong green: green result from wrong artifact/window/test/generation/scope — must be refused.

Promise Keeper / Keeper: hat guarding requirement fidelity. Radius threshold: repo policy value escalating disposition/approvals. Distinguisher collapse: sole evidence for safety claim proven insensitive, voiding claim. Headroom decomposition: splitting under-ceiling file mixing responsibilities. Germination tiers: germinated/legacy/ungerminated docs statuses. Land-order coordination: overlapping window blocked until prior PR lands (adjudication tiebreak 1). Value-free: receipts containing identities/digests/codes only. Developer-action hit: suggestion counted only when developer acted (benchmark). Maintainer: platform-permission holder of merge authority (never inferred). Community reviewer: evidence producer without merge grant. Pre-authorization: maintainer grant object for named fix class with bounds/expiry. Wrong-green refusal: adjudicator duty to reject green from wrong artifact/window/test/generation/scope.
