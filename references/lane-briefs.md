# Reference: Lane Brief Templates (dispatch contracts; orchestrator fills, never freelances)

Analyst brief: pin, region/window, promise refs, obligations (six artifacts), allowlist (source at pin, graph query), forbidden (witness outputs, expected verdict), deliverable (file >10KB equivalent structured artifact + hashes), deadline/cost ceiling.
Witness brief: same pin/region/obligations, allowlist excludes paired analyst output (tool-enforced), attention classes (failure gallery relevant kinds), own golden hash required, deliverable before any comparison access (access logged — log is isolation evidence).
Adjudicator brief: both deliverables + pin, duty re-verify load-bearing claims at source (not vote), tiebreak order, output contract (window/invariants/probes/blocked alternatives) or QUESTION escalation.
Implementer brief: contract only (+ repo check files), no witness reasoning, seam preservation, tests required (identity + behavioral + sensitivity), commit without push.
Reviewer (correctness): candidate pin + contract + promise; verdict + tuples; approval binds exact head.
Reviewer (adversarial): candidate pin, gallery classes by radius, hostile probes encouraged, same verdict form.
Fix lane: rejection tuples + contract delta; repaired head returns to both reviewers.
Triage (advisory): advisory + graph snapshot gen, reachability proof obligations, NO_ACTION scope form.
Brief anti-patterns (orchestrator rejected): "confirm this is safe" (expected answer contamination), missing pin, missing cost ceiling, reasoning included in implementer brief, witness brief listing analyst conclusions as "context."
