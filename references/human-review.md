# Reference: Human Review Practice (how humans + Rev share work)

Rev augments, never impersonates, human reviewers. Humans bring requirement ownership, taste with accountability, organizational memory. Lanes bring census scale, sensitivity probes, bookkeeping stamina.

Division protocol: lane output labeled as lane output; human may adopt (adoption = human finding with own identity, lane credited as investigator), challenge (witness role), or dismiss with coded reason (feeds calibration, knowledge-mapping §15). Maintainers see both layers; summaries never merge identities.

Human sitting discipline (empirical envelope): request reviews sized 200-400 LOC equivalents (radius-chunked by Rev into sittings with maps), async with response-time expectations per repo policy (not ambient SLA claims), reviewer load visible (registry: open sittings per person, 30-day balance). Review requests routed by familiarity graph + load + Busy (knowledge-mapping §14).

Onboarding: new reviewers pair via gallery drills + shadow sittings (review after lane, compare tuples before seeing verdict? No — independent first, then compare: blindness as training). First-year usefulness curve: assign narrow-radius sittings with strong maps, grow radius with witnessed competence scope (accountant records).

Etiquette as protocol: Conventional Comments labels, praise sincerely, questions with named objects, no drive-by severity, update conclusions on new pins, credit fiercely (people are technical record, Intro Ch.14: future agents retrieve these comments — write for that reader).

## Mentorship + culture operations
Review feedback quality sampled (acted rate by reviewer, coded dismissals) used for coaching, never public shaming leaderboards (gaming + retention harm — Tidelift burnout data: process must reduce load). Maintainer load protection: Rev absorbs first-pass census/probes; humans get maps + decisions. Rotation + Busy honored; vacation coverage = explicit acting grants. Recognition: praise + credit ledger surfaced in contributor reports (retention infrastructure for OSS: ~1/4-1/3 incoming AI-era queue load makes triage relief existential — vuln/ops files).
Conflict protocol: disagreement on interpretation -> owner decision recorded; disagreement on evidence -> new distinguisher designed jointly; personal escalation never substitutes (labels keep tone machine-parseable and human-kind).

## Maintainer decision hygiene
Decision comment separates: assessment adopted (which lane/human findings), requirement calls (owner), risk acceptance (grant + expiry if any), merge authorization identity. Future readers (and agents retrieving history) reconstruct why without chat archaeology. Reversals update conclusions at new pin (Intro Ch.13-14) — maintainers model this first; lanes follow.
