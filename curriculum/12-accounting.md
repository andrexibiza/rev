# Module 12 — Accounting: Memory That Cannot Quietly Lie

Primitives: Evidence across time, Authority, Promise. Hat: findings accountant. Sources: AGMD interlock/credit (§§3.6,20), Intro Ch.7, Ch.14, schema Receipt/GraphEdge.

Ledger first principle: future decisions inherit today's record. Unsupported allegation summarized without limits becomes false system knowledge; repaired defect without updated conclusion becomes phantom current defect. Therefore: conclusions are versioned objects pinned to artifacts; updates append, never silently edit; credit (investigator, implementer, witnesses, reviewers, authorizer, fixture authors incl. public handles) is structured data; interlock is bidirectional graph (issue<->PR<->advisory<->receipt) with honest gaps listed (unbound items, caps, unpaginated shards disclosed — AGMD Exhibit A audit limits as anti-pattern gallery).

Diagrams are ledger views (systems-mapping): pin + generation + query identity rendered; stale watermark on pin move. GraphQL registry filters (awaiting maintainer, reachable+exploitable, indeterminate) are accounting queries, not UI inventions.

Debt accounting: 2K manifest, flaky manifest, legacy severity tiers — each entry has owner, allowance, removal condition bound to verified shipping/merging receipt. Raising allowance to silence gate is accounting fraud; gate failure with honest manifest update + owner decision is governance.

Curriculum maintenance: every incident, refused green, and novel defect class files a curriculum delta (new failure-gallery entry + exercise) reviewed like code. This file set is living infrastructure (AGMD §3.5 skills as executable context). Graduation: learner (human or lane config) passes module exercises against pinned repos with receipts; accountant records geometry + scope of competence — never blanket "reviewer certified."

Capstone (Blind Witness Ch.20): refuse the wrong green result — wrong artifact, wrong window, insensitive test, stale generation, partial audit, widened scope, self-certification. When unsure which green is wrong, settle INDETERMINATE and reconcile. The ledger remembers; make it worth inheriting.

## Studio: ledger audit
Sample 20 historical PRs in any active repo: reconstruct investigator/implementer/reviewer/authorizer, unbound items, conclusions never updated after repair. Publish gap list with counts (honest-gap rule). Then design minimal ledger fields that would have prevented top 3 gaps — compare with schema.md Receipt/GraphEdge (differences argued, schema updated via RFC if learner wins argument).

Graduation audit: candidate lane/human reviews seeded fixture PR; accountant scores tuple completeness, scope honesty, credit accuracy, refusal correctness. Blanket certification never issued — scope recorded (kinds, radius, ecosystems witnessed).
